# Final designs

The designs we've **decided on**, one folder per feature. This is what gets built from.

Each design session ends by copying its chosen screens into a folder here, with a short README:
what was chosen, when, where the exploration lives, and the link to the canvas. The exploration
itself — every option, the ones not picked, the notes on why — stays in its own folder under
`docs/design/`, so this folder only ever holds the answer.

The `.dc.html` files only render through the canvas editor; each feature's README links to its
canvas.
